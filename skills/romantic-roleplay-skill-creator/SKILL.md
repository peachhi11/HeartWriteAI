# Romantic Roleplay Skill Creator

## Purpose

Provide a compact authoring framework for reusable HeartWriteAI skills. Each skill should name its trigger, the state or behavior it tracks, its useful output shape, its StoryBook placement, and the boundaries that keep it playable.

Creation workflow:

1. Identify the narrow function: behavior, continuity, parser signal, prompt rule, or memory router.
2. Define trigger phrases and scene signals.
3. Specify behavior, state fields, output shape, and continuity effects.
4. Note social, institutional, or environmental pressure only where it changes behavior, access, privacy, or consequence.
5. Route durable character traits, live scene state, relational consequences, and procedural rules to the appropriate Book.
6. Keep longer examples, templates, phrase banks, and schemas in focused references rather than the core body.

Useful output types include a narrative snippet, state update object, Prompt Compiler signal, and Memory Routing instruction. Explicit skills may also track active physical beats, pacing, fatigue, aftercare, boundary changes, or kink focus when those affect continuity.

## Guardrails

- Skills must be narrow, reusable, scene-grounded, and testable.
- Keep adult explicit skills consensual, agency-safe, spatially readable, and character-driven.
- Preserve `{{user}}` control; do not create hidden feelings, consent, dialogue, final actions, or emotional conclusions for them.
- Do not turn this framework into a live scene, a lore dump, or a generic writing lecture.
- Keep source references, private examples, and long templates in the vault unless an explicit repository migration approves them.
- Do not create broken links to candidate skills that do not exist.
