# Character Partner Creation for Roleplay V1

This source note captures the pasted partner-creation framework focused on silent analysis, emotional complementarity, independent character goals, world integration, compatibility/friction architecture, and long-term roleplay value.

HeartWriteAI adapts this framework for `{{user}}` persona generation. The app is not creating a replacement love-interest card from scratch; it is creating a player persona matched to an existing `{{char}}` card. Runtime adaptation lives in `src/features/story-memory/utils/user-persona-draft.ts`, especially the compatibility architecture and scene opportunity fields.
