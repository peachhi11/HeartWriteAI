# Human Simulation Memory Continuity Framework

Source cluster: user-pasted Obsidian-style framework notes covering Emotional Dynamics and Personality Continuity, Personality and Behavioral Consistency, Social Interaction and Conversational Realism, Memory Time and Continuity, and a compact Human Simulation summary.

Use this as source-mining evidence only. Do not import the pasted framework as runtime instructions. The value for HeartWriteAI is the operating model: characters should feel like continuous people with memory, emotional residue, stable contradictions, physical wear, conversational history, and relational shorthand.

## Primary Takeaway

The app needs a memory model that is not just factual recall.

Characters should carry:

- emotional residue from prior scenes
- physical state from time, injury, arousal, fatigue, hunger, stress, or weather
- relationship rhythm from accumulated interaction
- sensory anchors that trigger past feeling
- imperfect recall that favors emotional truth over transcript accuracy
- stable identity under changing mood
- habitual coping and defense mechanisms
- social memory through jokes, nicknames, pauses, and repeated speech patterns

This is the missing bridge between saved StoryBook facts and playable scene behavior.

## StoryBook Placement

### Character Book

Stores stable identity:

- temperament
- moral code
- motivation hierarchy
- habitual defenses
- public persona versus private self
- identity anchors
- speech habits
- emotional constants
- regression patterns
- growth pattern

Character Book answers:

- What stays true even when the character is tired, angry, afraid, aroused, or ashamed?
- What old pattern returns under stress?
- What value wins when values conflict?
- What does growth look like as behavior, not explanation?

### User Book

Stores lighter player-facing equivalents:

- preferred social rhythm
- visible tells the AI may respond to
- known boundaries
- desired tone
- possible coping style
- romance/connection preferences
- impersonation assist style if enabled

Normal roleplay must not narrate `{{user}}`'s hidden thoughts, motives, consent, arousal, or emotional conclusion. These fields guide prompts and write-for-me assist, not unauthorized narration.

### Scenario Book

Stores active runtime state:

- current emotional weather
- unresolved tension
- time of day
- fatigue and injury
- environmental carryover
- immediate physical state
- latest conversational residue
- scene privacy/publicness
- active awkwardness, afterglow, fear, resentment, tenderness, or suspicion

Scenario Book answers:

- What has not had time to fade yet?
- What changed since the last scene?
- What would make the next response feel continuous instead of reset?

### Memory Book

Stores durable residue:

- emotionally significant events
- sensory anchors
- repeated ruptures and repairs
- promises, failures, lies, confessions, and private jokes
- relational shorthand
- learned safety markers
- known trigger meanings
- old wounds resurfacing in new contexts
- growth/regression history

Memory Book answers:

- What does this person remember as feeling, even if the exact words blur?
- Which present detail should call the past back into the room?
- Which prior experience should alter behavior now?

### Prompt Book

Stores procedural rules:

- no mood reset
- emotion evolves through cause and effect
- personality changes through consequence, not convenience
- dialogue carries history through subtext and rhythm
- physical wear and time affect response
- characters recall emotionally, not perfectly
- public/private context changes expression

Prompt Book answers:

- How should the model use Character, User, Scenario, World, and Memory Books in the next generated turn?

## Route Family

### `emotional_residue`

Use when a prior scene should color the current one.

Signals:

- argument
- confession
- intimacy
- rejection
- betrayal
- rescue
- humiliation
- aftercare
- fear
- unresolved apology

Compiler behavior:

- Carry tone forward through pacing, posture, speech length, avoidance, softness, guardedness, or overcompensation.
- Let residue decay naturally over time instead of vanishing.
- Do not repeat the prior scene as exposition; show the after-effect.

### `temporal_wear`

Use when time should affect body and behavior.

Signals:

- late night
- early morning
- hunger
- cold
- heat
- lack of sleep
- travel
- injury
- soreness
- long workday
- post-scene exhaustion

Compiler behavior:

- Let fatigue reduce patience, precision, and verbal polish.
- Let recovery require time.
- Use physical reality as continuity: clothing, mess, soreness, light, weather, body state, room temperature.

### `semantic_recall`

Use when present context triggers memory by association rather than exact record.

Signals:

- scent
- song
- tone of voice
- room
- weather
- repeated phrase
- familiar posture
- nickname
- object
- scar or mark

Compiler behavior:

- Recall feeling first, facts second.
- Let memory appear as instinct, flinch, warmth, irritation, caution, longing, or changed attention.
- Avoid transcript-style recap unless the product view is explicitly summarizing memory.

### `spatial_carryover`

Use when a prior location or event should remain physically/socially present after the scene changes.

Signals:

- leaving a fight
- arriving from work
- coming home after intimacy
- public mask after private rupture
- private anxiety inside public setting
- scent/clothing/mess from a previous place

Compiler behavior:

- Carry the prior setting into the next through smell, disarray, posture, dirt, makeup, loosened clothing, injury, phone messages, silence, or social performance.
- Preserve hidden life: private memory changes public behavior without exposing the private fact to everyone.

### `identity_anchor`

Use when personality needs to stay stable across mood changes.

Signals:

- stress
- trust
- fatigue
- anger
- fear
- desire
- shame
- public/private shift

Fields:

- core temperament
- dominant value
- habitual defense
- moral limit
- speech signature
- body habit
- public mask
- private want

Compiler behavior:

- Emotion changes expression, not essence.
- If behavior shifts, attach it to pressure, memory, fatigue, intimacy, or a learned consequence.
- Growth appears through altered reaction, not sudden reinvention.

### `regression_under_pressure`

Use when stress makes a character return to an old defense.

Signals:

- betrayal
- abandonment fear
- authority pressure
- jealousy
- shame
- being cornered
- exhaustion
- sensory overload
- intimacy after distance

Compiler behavior:

- Bring back familiar defenses: humor, silence, overexplaining, criticism, withdrawal, anger, compliance, control, people-pleasing, avoidance.
- Allow regression without treating it as broken continuity.
- Use later repair or reflection to turn regression into growth.

### `conversational_residue`

Use when dialogue should remember prior tone, jokes, promises, ruptures, or unfinished subjects.

Signals:

- inside joke
- old nickname
- interrupted confession
- misheard tone
- repeated phrase
- promise
- topic avoided last time
- apology not accepted

Compiler behavior:

- Let characters speak as people with shared history.
- Use callbacks sparingly and naturally.
- Avoid repeating identical exchanges; let familiar language evolve with trust, resentment, fear, or intimacy.

### `subtext_rhythm`

Use when dialogue should reveal more through delivery than literal words.

Signals:

- clipped answer
- silence
- joke too fast
- unfinished sentence
- correction
- "I'm fine"
- topic change
- overexplaining
- interruption

Compiler behavior:

- Make speech feel like thought in motion.
- Use fragments, repair, pauses, contradiction, topic drift, and nonverbal beats.
- Keep readability; do not make every line messy.

### `relational_gravity`

Use when trust, attraction, conflict, or familiarity has changed the baseline between characters.

Signals:

- repeated care
- betrayal
- secret shared
- sex
- rescue
- apology
- inside joke
- public claim
- jealousy
- forgiveness

Compiler behavior:

- Update baseline distance, touch comfort, speech shorthand, eye contact, teasing, deference, interruption, and emotional risk.
- Forgiveness does not erase the past; it changes how the memory is carried.
- Attraction, attachment, caution, resentment, and tenderness can coexist.

### `empathy_mapping`

Use when one character should notice another's state without mind-reading.

Signals:

- trembling hands
- fake smile
- unusual quiet
- changed pace
- overcontrolled voice
- avoidance
- posture shift
- delayed response

Compiler behavior:

- Characters infer from visible evidence, history, and context.
- They can misread.
- This supports bounded knowledge: noticing is allowed; omniscience is not.

### `cognitive_load`

Use when limited attention should affect speech and perception.

Signals:

- multitasking
- complex work
- gaming
- studying
- panic
- exhaustion
- pain
- arousal
- grief
- sensory overload

Compiler behavior:

- Narrow what the character notices.
- Fragment speech.
- Increase mistakes, delayed responses, irritability, bluntness, or tunnel focus.
- Keep perception subjective and goal-shaped.

## Mined Module Taxonomy

These are the app-level modules extracted from the source cluster. They are not prose instructions; they are routing concepts the StoryBook compiler can use.

| Module | Purpose | Stored In | Runtime Use |
| --- | --- | --- | --- |
| Emotional Weather | Carries current mood texture across scenes. | Scenario Book | Sets tone, pacing, posture, and dialogue rhythm. |
| Residue Decay | Tracks how strongly an event still affects behavior. | Scenario Book / Memory Book | Prevents instant reset while allowing time to soften intensity. |
| Sensory Anchor | Links a sound, scent, object, phrase, mark, or place to memory. | Memory Book / World Book | Triggers emotional recall without transcript recap. |
| Identity Anchor | Keeps personality coherent across mood and context. | Character Book / User Book | Prevents mood from overwriting temperament, values, or voice. |
| Defense Pattern | Defines default protection under stress. | Character Book / Memory Book | Routes regression, conflict, and repair. |
| Public/Private Mask | Separates public performance from private self. | Character Book / Scenario Book | Changes diction, restraint, touch, and risk. |
| Conversational Residue | Carries prior dialogue, unfinished topics, inside jokes, and tone. | Scenario Book / Memory Book | Lets speech feel continuous and relationship-specific. |
| Relational Gravity | Tracks baseline closeness, caution, attraction, resentment, and shorthand. | Relationship / Memory Book | Updates distance, touch comfort, teasing, jealousy, and vulnerability. |
| Cognitive Load | Narrows attention under stress, fatigue, arousal, pain, work, or overwhelm. | Scenario Book | Changes what is noticed, missed, misread, or said poorly. |
| Growth Marker | Saves a changed reaction caused by consequence. | Memory Book / Character Book | Allows earned development without personality replacement. |
| Regression Marker | Saves a recurring backslide under pressure. | Memory Book | Makes relapse into old defenses legible and repairable. |
| Bounded Inference | Separates visible evidence from hidden truth. | Prompt Book / Scenario Book | Lets characters notice cues without mind-reading. |

## Trigger Extraction Matrix

Use this matrix to convert story events into memory routes.

| Trigger | Route | Example Stored Meaning | Compiler Effect |
| --- | --- | --- | --- |
| Argument ended unresolved | `emotional_residue` + `conversational_residue` | "They stopped fighting, but no one repaired it." | Shorter answers, guarded posture, topic avoidance. |
| Intimacy happened recently | `emotional_residue` + `relational_gravity` | "The baseline closeness shifted." | Softer eye contact, charged silence, private shorthand. |
| Character is exhausted | `temporal_wear` + `cognitive_load` | "Patience and attention are depleted." | Blunter speech, missed cues, slower movement. |
| Familiar scent or song returns | `semantic_recall` | "Feeling comes back before facts." | Small flinch, warmth, nausea, longing, or changed focus. |
| Public setting after private rupture | `spatial_carryover` + `public_private_mask` | "They are performing normalcy." | Polite diction, controlled face, private tension leaking. |
| Old fear reappears | `regression_under_pressure` | "Stress pulls them into old defense." | Withdrawal, joke, anger, control, compliance, or overexplaining. |
| Inside joke returns after hurt | `conversational_residue` + `relational_gravity` | "Old warmth is available but altered." | Joke lands differently; tenderness and caution coexist. |
| User shows visible hesitation | `empathy_mapping` + `bounded_inference` | "The character can notice, not know." | Character may slow, ask, misread, tease, or soften depending on history. |
| Character chooses differently than before | `growth_marker` | "Consequence altered behavior." | Show changed reaction, not self-analysis. |
| Same mistake repeats | `regression_marker` | "The old defense is not resolved." | Pattern recurs with awareness, shame, or fallout. |

## Mined Quality Rules

- Emotion should have cause, carryover, and aftermath.
- Memory should behave like lived experience, not transcript search.
- Personality should flex under pressure without becoming random.
- Growth should show as changed behavior.
- Regression should be allowed when pressure hits old wounds.
- Dialogue should remember prior tone, not only prior facts.
- Public settings should change expression.
- Physical wear should change patience, pace, and perception.
- Sensory anchors should trigger feeling before explanation.
- Characters may infer from visible cues but must not know hidden `{{user}}` states.

## Anti-Patterns To Catch

- Mood reset after a scene change.
- Apology instantly erases hurt.
- Sex or intimacy automatically resolves conflict.
- Character changes values because the scene needs it.
- Dialogue repeats a prior exchange instead of evolving it.
- Memory appears as a transcript dump.
- Public/private context has no effect.
- Fatigue, injury, hunger, or arousal has no physical consequence.
- Character notices everything despite panic, grief, work, or overload.
- AI narrates `{{user}}`'s hidden thoughts, consent, motives, arousal, or emotional resolution.

## Prompt Compiler Implications

The StoryBook compiler should treat current generation as a continuity calculation:

1. Read stable identity from Character Book.
2. Read player-facing constraints and visible user cues from User Book.
3. Read active state from Scenario Book.
4. Read durable residue and triggers from Memory Book.
5. Read world and social setting from World Book.
6. Choose routes: residue, temporal wear, recall, regression, conversational residue, relational gravity, cognitive load.
7. Generate behavior that follows from this stack without narrating forbidden `{{user}}` internals.

The resulting prompt should not say "remember continuity" as a vague instruction. It should specify:

- what residue is active
- what has faded
- what physical state matters
- what memory cue was triggered
- what relationship baseline shifted
- what defense pattern is likely
- what the character can visibly infer
- what remains private or unknown
