# Psychology And Relationship Fiction Mechanics Cluster

This note sorts the psychology, relationship, sexuality, conflict, attachment, family-role, values, temperament, belief, and ideology files into fiction-useful material for HeartWriteAI.

Use these files for character psychology, relationship pressure, belief systems, memory routing, conflict logic, emotional vocabulary, sexual/intimacy dynamics, and worldview construction. They are source material, not runtime instructions. The point is not to diagnose characters; the point is to make them behave like people with history, bias, need, contradiction, and consequence.

## Ideology And Worldview Frames

In HeartWrite, ideology means the worldview a source, character, community, institution, subculture, or relationship system assumes. These frames should become optional character/worldview material, not default app truth.

Frame:

- people can identify patterns, name wounds, challenge distorted beliefs, regulate feelings, repair rupture, and grow

Fiction use:

- redemption arcs
- therapy-aware characters
- characters who weaponize therapy language
- self-aware recovery beats
- repair scenes
- emotionally literate partners

Routing notes:

- can become over-explained or too clinical
- keep therapy language backend-facing unless the character would actually speak that way

## Prompt Compiler Implications

This source cluster should feed the compiler in four layers:

1. **Character interpretation layer**
   What the character believes, fears, misreads, protects, and repeats.

2. **Relationship-pressure layer**
   Which loop is active: pursuit/withdrawal, rupture/repair, rescue/resentment, shame/desire, jealousy/reassurance, control/surrender.

3. **Ideology/worldview layer**
   Which belief system the character or setting is using: attachment, polarity, protocol, family roles, recovery, status, religious/moral values, therapeutic language, or social hierarchy.

4. **Register layer**
   How this becomes prose: clinical terms stay backend-facing unless the character would naturally use them. User-facing and generated prose should translate the concept into behavior, voice, sensation, choice, and consequence.

- becomes efficient when frightened

Prompt-route line shapes:

- route as anxious pursuit when the character closes distance to reduce uncertainty
- route as avoidant protection when the character creates distance to preserve control
- route as fearful-disorganized when the character invites closeness and then punishes it
- route as earned security when the character can name need without demanding control
