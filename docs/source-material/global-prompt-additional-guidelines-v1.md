# Global Prompt Additional Guidelines V1

This source note captures the second global-prompt artifact: a structured guideline template organized around rule, reasoning, context, failure, success, and exclusion checks.

The runtime adaptation lives in `src/features/story-memory/data/global-prompt-stack.ts` under `Additional Guideline Diagnostics`. It is intentionally compacted so the app keeps one coherent Global Prompt instead of exporting two overlapping global prompts.
