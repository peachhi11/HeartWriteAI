# Source Material

This folder stores recovered or external writing-system artifacts that inform HeartWriteAI's prompt, persona, lorebook, and story-memory design.

These files are reference material, not runtime instructions. Inspect them as source artifacts before adapting anything into app data, prompt seeds, tests, or UI copy.

## Inbox

- `inbox/` - app-side source intake for raw or lightly processed material that may later be promoted into stable source notes, app registry metadata, tests, or runtime implementation.

Inbox files are not canonical until reviewed. Check this folder periodically during source-mining, indexing, skill, prompt compiler, and app registry work.
