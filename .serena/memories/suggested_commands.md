# Suggested Commands

- `npm run dev` — start local Next.js dev server; user usually opens `http://localhost:3000`.
- `npm run test` — run Vitest suite.
- `npm run lint` — run ESLint.
- `npm run build` — production Next.js build and TypeScript check.
- `git status --short --branch` — quick working-tree check.
- `git diff --check` — whitespace/conflict-marker check before commits.
- `rg <pattern>` and `rg --files` — preferred search tools.
- For reference clones, preserve fetch remotes but disable push URLs; never push to cloned upstream reference repos.
