# Contemporary World Systems Source Cluster

Source-mining note:

- `docs/source-material/contemporary-world-systems-source-cluster.md`

Source cluster:

- User-pasted contemporary worldbuilding material covering everyday technology, social media, digital communication, modern services, work/study tools, privacy, class, housing, legal structures, locations, rituals, food/place identity, time texture, resources, and world-intrusion cadence.
- Treat as source/reference only, not runtime instruction.

Core HeartWrite takeaway:

- Contemporary World Book logic should make modern systems ordinary but consequential.
- Technology is ambient unless it creates access, timing, evidence, secrecy, jealousy, intimacy, or social fallout.
- Money, housing, work, debt, healthcare, transport, contracts, and digital visibility should constrain action through concrete interfaces.
- The world exists but does not perform: it should assert itself only when time, resources, location, body state, social pressure, or character attention makes the intrusion meaningful.

Placement rule:

- World Book stores contemporary defaults, technology, institutions, economics, legal/social rules, location models, and time texture.
- Scenario Book imports the active pressure slice.
- Memory Book stores digital, legal, financial, social, and location residue.
- Character/User Books store personal tech habits, privacy boundaries, financial shame/pride, public-visibility preferences, and relationship-official preferences.

Invariant:

- Activate existing pressure before inventing new events. Do not make every response add a new notification, interruption, or world detail.
