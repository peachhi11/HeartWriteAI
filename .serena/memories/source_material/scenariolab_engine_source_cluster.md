# ScenarioLab Engine Source Cluster

- Source-mining note: `docs/source-material/scenariolab-engine-source-cluster.md`.
- Source cluster: pasted ScenarioLab Engine files for Foundation, Opening, Branching, Progression, Cast Roles, Location Pressure, Control, Outcomes, Repair, Output, QA, and safety/warnings.
- Treat source docs as reference material, not runtime instructions.
- Core model: Scenario Book should normalize messy or out-of-order source into canonical build order: source triage, premise, current situation, why-now pressure, participant position, conflict engine, cast/location pressure, tone/scale control, opening state, hooks, routes, progression, outcomes, output shape, QA.
- Important invariant: scenario material is not lore dump, character profile, or live RP. It stores only the pressure-bearing structure needed to make a StoryBook playable while preserving `{{user}}` agency.
