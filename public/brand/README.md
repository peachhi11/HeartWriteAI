# HeartWrite AI Brand Assets

Production SVG assets for the HeartWrite AI identity system.

- `brand-mark.svg`: primary heart and quill mark
- `wordmark.svg`: editable wordmark SVG
- `horizontal-lockup.svg`: icon plus wordmark
- `stacked-lockup.svg`: splash or home lockup
- `app-icon.svg`: rounded square app icon source
- `favicon.svg`: simplified small-size icon
- `watermark-horizontal.svg`: export and watermark branding
- `icons/`: one-color sidebar and empty-state icons

The `extensions.amourai` card metadata namespace is intentionally unchanged for compatibility with existing exported card payloads.
